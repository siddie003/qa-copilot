# Brightline Studio — Brand Guidelines

Version 2.1 · Approved by the Brightline brand team · Demo data for QA Copilot (Brightline Studio is a fictional company)

This document defines how the Brightline Studio website must look. Every value below is written literally so it can be checked against the live website.

## 1. Brand identity

Brightline Studio builds marketing websites that brand teams can sign off without surprises. The visual language is calm, precise and readable: one typeface, one accent colour, generous white space.

## 2. Colour palette

Brand blue — #1A56DB

Primary text color — #1F2937

Heading color — #111827

Link color — #1A56DB

Page background — #FFFFFF

Header background — #F3F4F6

Footer background — #111827

Border grey — #E5E7EB

Only these colours may be used for text, backgrounds and borders. Near-miss shades (for example a slightly different blue) are not allowed.

## 3. Typography

Primary font: Geist

Geist is used for every heading, paragraph, link, button and form field. It is served as a web font (WOFF2). The licensed font files are distributed with these guidelines (Geist-Variable-Latin.woff2 and Geist-Regular.ttf, SIL Open Font License 1.1). No other typeface may be used, and the browser must never fall back to a system font.

### Heading hierarchy

Each heading level has exactly one style. Lower levels are never larger than higher levels.

H1 — Geist Bold, 48px / 56px, #111827

H2 — Geist Semibold, 32px / 40px, #111827

H3 — Geist Semibold, 24px / 32px, #111827

H4 — Geist Semibold, 20px / 28px, #111827

H5 — Geist Semibold, 18px / 28px, #111827

H6 — Geist Semibold, 16px / 24px, #111827

All headings use the normal (upright) style; italic headings are not allowed.

### Body text and interface text

Body text — Geist Regular, 16px / 24px, #1F2937

Button text — Geist Semibold, 16px / 24px

Introduction paragraphs may use 20px with 32px line height.

## 4. Spacing and layout

Spacing scale (pixels): 4, 8, 16, 24, 32, 48, 64. Margins, paddings and gaps use only values from this scale.

Content container: maximum width 1200 pixels, centred, with 24 pixel side padding.

Section spacing: 48 pixels above each section heading (H2), 16 pixels below it.

Cards: 24 pixel padding, 1 pixel border in Border grey, 8 pixel corner radius, 24 pixel gap between cards.

Repeated items (cards, list entries, service blocks) are always evenly spaced.

## 5. Alignment

All text and content blocks inside a section are left-aligned on the same edge. Indentation is only used for lists (24 pixels).

## 6. Buttons and components

Primary button: background Brand blue, white text, 8 pixel corner radius, padding 12 pixels top and bottom and 24 pixels left and right, Geist Semibold.

Every form field has a visible label above it.

## 7. Images

Images are delivered at least at the size they are displayed (twice that size for high-density screens) and are never stretched or squashed: the original proportions are always kept.

Every content image has a short alternative text; purely decorative images use empty alternative text.

## 8. Responsive behaviour

Pages must fit the screen at 390, 768 and 1440 pixels wide without sideways scrolling. Touch targets are at least 24 by 24 pixels.
