# Approachable Design — Brand Guidelines (QA test reference)

Test reference for QA Copilot, written on 2026-10-17 from measurements of the live page https://www.approachabledesign.co/newsletter/ (computed styles in Chromium at 1440px wide). This is not an official document of Approachable Design; it records how the site is currently built so the scan can check consistency against it.

## 1. Colour palette

Primary text color — #0B0A16

Page background — #FFECE2

Header background — #FFECE2

Brand purple — #5148CA

Body copy uses Primary text at 70–80% opacity; headings use it at full strength.

## 2. Typography

Heading font: Domaine Display Black Italic

Body font: Inter

Headings use the Domaine Display Black Italic web font (a licensed commercial typeface, served by the website itself). Body copy uses Inter. Navigation, buttons and small labels use Manrope. Inter and Manrope are distributed with these guidelines under the SIL Open Font License; Domaine Display is not.

### Heading hierarchy

H1 — 72px / 72px, weight 900, italic, #0B0A16

H2 — 24px / 32px, weight 900, italic, #0B0A16

H4 — Manrope Semibold, 14px / 20px, letter spacing 0.7px

Each heading level has one style; lower levels are never larger than higher levels.

### Body and interface text

Body text — Inter Regular, 18px / 28.8px, #0B0A16

Button text — Manrope Semibold, 16px / 24px

Introduction paragraphs at the top of a page may use 20px with a 28px line height.

## 3. Layout and spacing

Content container: maximum width 1200 pixels, centred. Reading width for text sections: 768 pixels.

Primary button: background Brand purple, white text, fully rounded (pill) corners, padding 16 pixels top and bottom and 24 pixels left and right.

## 4. Images and responsive behaviour

Images are delivered at least at their displayed size and keep their proportions. Pages fit the screen at 390, 768 and 1440 pixels wide without sideways scrolling.
